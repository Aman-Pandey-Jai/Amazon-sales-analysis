# 📊 Amazon Sales Dashboard
🛍️ Project Overview

This project presents a Sales Analysis Dashboard for Amazon Products, created to visualize and monitor key performance indicators (KPIs) such as total sales, quarterly sales, products sold, and customer reviews. The dashboard helps in understanding sales trends, product performance, and category contributions throughout the year.

📈 Purpose

The goal of this project is to:

Analyze sales performance and customer engagement across categories.

Track trends in monthly and weekly sales.

Identify top-performing products and categories.

Enhance data-driven decision making for product management and marketing teams.
